# Data notes

- `raw/2026_MCM_Problem_C_Data.csv` is the competition dataset used for the contestant-feature analysis.
- `processed/mcm_panel_by_week.csv` is the cleaned season-week-contestant panel used by the reconstruction model.
- `results/` contains the checked-in outputs used by downstream scripts and figures.

The processed and result files are included so that the statistical analyses can be reproduced without rerunning the simulation-intensive vote reconstruction. Users should consult the original MCM problem source for the dataset's terms of use and full field definitions.
